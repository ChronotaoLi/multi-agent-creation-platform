# 如何使用

1. 将上面的配置保存为`docker-compose.yml`文件
2. 在该文件所在目录运行以下命令启动所有数据库：

```bash
docker-compose up -d
```

3. 验证所有容器是否正常运行：

```bash
docker-compose ps
```

# 数据库连接信息

数据库启动后，您可以使用以下信息进行连接：

### PostgreSQL
- **主机**: localhost
- **端口**: 5432
- **用户名**: postgres
- **密码**: postgres
- **数据库名**: ai_creation
- **连接URL**: `postgresql://postgres:postgres@localhost:5432/ai_creation`

## Redis
- **主机**: localhost
- **端口**: 6379
- **URL**: `redis://localhost:6379/0`

## Milvus
- **主机**: localhost
- **端口**: 19530
- **URI**: `http://localhost:19530`

## Neo4j
- **HTTP地址**: http://localhost:7474
- **Bolt URI**: bolt://localhost:7687
- **用户名**: neo4j
- **密码**: password

# 数据持久化

所有数据库的数据都通过Docker卷进行持久化存储，即使容器被删除，数据仍然会保留。卷名称如下：

- postgres_data
- redis_data
- milvus_data
- etcd_data
- minio_data
- neo4j_data
- neo4j_logs

如需完全清除所有数据，可以运行：

```bash
docker-compose down -v
```

这个配置仅包含数据库相关服务，您可以根据项目需要进一步定制或添加应用服务。
